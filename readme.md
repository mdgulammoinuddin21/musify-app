# 🎵 Musify - Spotify Clone

Musify is a full-stack Spotify clone application built using React, Spring Boot, MongoDB, and Cloudinary.

The project contains separate React applications for users and administrators, along with a Spring Boot REST API backend.

---

## 🚀 Tech Stack

### Frontend

- React
- JavaScript
- HTML
- CSS
- REST API

### Backend

- Java
- Spring Boot
- Spring Data MongoDB
- REST API
- Maven

### Database

- MongoDB

### Cloud Storage

- Cloudinary
